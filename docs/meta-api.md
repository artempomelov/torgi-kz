# Публикация через API Instagram и Threads

Скрипт `web/scripts/publish_meta.py` публикует Reels и посты Threads без браузера.

- API Meta бесплатный.
- Приложение разработчика нужно только для своих аккаунтов. Проверка Meta (App Review) для этого не нужна, приложение остаётся в режиме разработки.

## Один раз: приложение и токены (делает владелец)

Токены — как пароли.

- Никому их не отправлять, в чат тоже.
- Вставлять только в файл `C:\Users\artem\.torgi\meta.env`. Файл лежит вне репозитория.

### 1. Приложение

1. Откройте developers.facebook.com → «Мои приложения» → «Создать приложение». Войдите тем Facebook, который управляет torgi.kz.
   - Если кабинета разработчика ещё нет, Meta сначала попросит зарегистрироваться и подтвердить телефон или почту.
2. Введите название, например «torgi.kz publisher», и почту.
3. Выберите сценарии использования:
   - «Управление сообщениями и контентом в Instagram» (Instagram API);
   - «Доступ к Threads API».

   Если оба сразу выбрать нельзя, создайте приложение с Instagram, а Threads добавьте потом в разделе «Сценарии использования». Можно и отдельным приложением.
4. Бизнес-портфолио можно не привязывать. Публиковать приложение («Go live») не нужно.

### 2. Токен Instagram

1. «Сценарии использования» → Instagram → «Настроить» → «Настройка API со входом через Instagram».
2. В «Разрешениях» должны быть `instagram_business_basic` и `instagram_business_content_publish`. Второе при необходимости добавьте кнопкой «Добавить».
3. В шаге «Сгенерировать маркеры доступа» нажмите «Добавить аккаунт» и войдите в @torgi.kz.
4. Если Meta попросит роль тестировщика, примите приглашение в Instagram: Настройки → Разрешения сайтов → Приложения и сайты → Приглашения тестировщиков.
5. Напротив torgi.kz нажмите «Сгенерировать маркер» и скопируйте токен.
6. Вставьте токен в `meta.env` после `IG_TOKEN=`.

### 3. Токен Threads

1. «Сценарии использования» → Threads → «Настроить».
2. В «Разрешениях» добавьте `threads_content_publish`. `threads_basic` там уже есть.
3. В «Настройках» заполните три адреса: обратного вызова, удаления и деинсталляции. Во всех трёх можно указать `https://torgi.kz/`. Без них настройки не сохраняются.
4. Слева «Роли приложения» → «Роли» → «Добавить людей» → «Тестировщик Threads» → torgi.kz.
5. Примите приглашение в Threads: Настройки → Аккаунт → Разрешения сайтов → Приглашения.
6. В настройках Threads откройте «Генератор маркеров пользователя» → «Сгенерировать маркер доступа» у torgi.kz и скопируйте токен.
7. Вставьте токен в `meta.env` после `THREADS_TOKEN=`.

Сохраните файл и напишите в чат «токены вставил». Сами токены не присылайте. Проверка их значения не показывает:

```bash
PYTHONIOENCODING=utf-8 uv run -q --project backend --with httpx python web/scripts/publish_meta.py check
```

Токены действуют 60 дней. Команда `refresh` продлевает оба ещё на 60 дней. Запускать её можно, когда токену больше суток. Новый срок записывается в `meta.env`.

## Публикация (только по команде владельца)

Сначала посмотреть, что уйдёт:

```bash
... publish_meta.py reels 180 --dry-run
```

Опубликовать:

```bash
... publish_meta.py reels 180
```

```bash
... publish_meta.py threads 199 --topic "Квартира в Алматы"
```

После публикации скрипт сам:

- отмечает лот в `reels-used.json` / `threads/used.json`;
- записывает ссылку в `marketing/meta-published.jsonl`.

### Где лежат файлы для Meta

- Видео Reels загружается напрямую.
- Обложку Reels и фото Threads Meta скачивает сама по публичной ссылке. Скрипт кладёт их в отдельную ветку `social-media` этого (публичного) репозитория и даёт ссылки `raw.githubusercontent.com`.
- Ветка каждый раз перезаписывается, в ней только файлы последней публикации.
- Сайт и `update.yml` это не затрагивает. Push в main запустил бы пересборку сайта и мог бы вытеснить плановый запуск из очереди.

### Чем API хуже браузера

- Музыку из библиотеки Instagram не поставить. Наши ролики без звуковой дорожки, поэтому через API Reels выходит без звука.
- Тему Threads задаём только текстом (`--topic`), без выбора из подсказок.
- Отложенной публикации нет: пост выходит сразу.
- Превью ссылки в Threads у постов с фото не появляется. Карточку закрывать не нужно.
